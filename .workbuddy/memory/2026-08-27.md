## SettingsPanelActivity 空白屏修复 (R36)

### 根因
Gradle sourceSets 把 tokens/、themes/、samples/protocols/ 三个目录的**内容**平铺合并到 APK assets 根目录:
- `tokens/harmony-tokens.json` → APK: `harmony-tokens.json` (没有 tokens/ 前缀)
- `themes/tequ-4k-theme.json` → APK: `tequ-4k-theme.json` (没有 themes/ 前缀)
- `samples/protocols/settings-panel/updateComponents.json` → APK: `settings-panel/updateComponents.json`

但 SettingsPanelActivity.loadAssetAsString() 用了带目录前缀的路径:
- `"tokens/tequ-4k-tokens.json"` → 不存在 (且该文件本身也不存在)
- `"themes/tequ-4k-theme.json"` → 不存在
- `"samples/protocols/settings-panel/updateComponents.json"` → 不存在

结果: designTokenJson="{}", themeJson="{}", updateComponentsMsg="{}", updateDataModelMsg="{}"
→ createSurface 发了空的 theme/designTokens, 后续两轮 begin/receive/end 发的是 "{}", 引擎无组件可渲染.

### 修复
1. 创建 `tokens/tequ-4k-tokens.json` — 引擎 TokenParser 要求 {"designTokens":{...}} 格式
2. 修正 SettingsPanelActivity asset 路径:
   - `"tequ-4k-tokens.json"` (非 `tokens/tequ-4k-tokens.json`)
   - `"tequ-4k-theme.json"` (非 `themes/tequ-4k-theme.json`)
   - `"settings-panel/updateComponents.json"` (非 `samples/protocols/settings-panel/...`)
   - `"settings-panel/updateDataModel.json"` (非 `samples/protocols/settings-panel/...`)
3. 字体注册改为 try-catch (fonts/ 目录不存在, 3 个 .ttf 都不在 assets 中)
4. designTokenJson fallback 从 `"{}"` 改为 `"{\"designTokens\":{}}"` (满足 TokenParser 的 contains 检查)

### 验证
- APK 内 assets 确认: tequ-4k-tokens.json (1334B), tequ-4k-theme.json (2106B), settings-panel/updateComponents.json (18938B), settings-panel/updateDataModel.json (2827B)
- uiautomator dump 确认完整渲染: "打开设置"按钮、设置标题、7个分类导航(企业服务/声音与显示/摄像机/壁纸/Wi-Fi/智慧功能/高级设置)、搜索框、右侧内容区(自动登录/企业账号绑定 switchItems, 扬声器音量/屏幕亮度 sliderItems, 服务器配置/企业账号管理 linkItems)、版本页脚"设备版本：V4.1.0"
- AGenUI 引擎日志确认: updateDataModel success, bind /data/linkItems, /data/sliderItems 等数据绑定正常

### 关键教训
- Gradle assets srcDirs 合并是**平铺**的: 目录内容直接放到 APK assets 根, 不保留目录前缀
- 引擎 TokenParser.loadFromJsonString 要求外层 {"designTokens":{...}} 包裹, 不是直接的 token 对象
- 引擎 parseCreateSurfaceData 不解析 theme/designTokens 字段 — 这些通过 registerDefaultTheme() 独立加载
